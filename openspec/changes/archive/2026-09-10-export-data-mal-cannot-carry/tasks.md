## 3. The export file and service

- [x] 3.1 Add `Services/Transfer/ExportFile.cs` with records mirroring the brief's JSON (D4, D5):
  - The records are `ExportFile`, `ExportDevice(Guid Id, string? Name)`, `ExportRanking`, `ExportAnimePicture`, `ExportSeries`, `ExportSeriesChoice` and `ExportActivity`.
  - Every time is a `DateTime` of kind `Utc`, and nullable where the spec allows null.
  - `ExportSeries.Title` and `.Picture` are nullable and marked `[JsonIgnore(Condition = JsonIgnoreCondition.WhenWritingNull)]`. No other property carries that attribute.
  - `ExportActivity.Id` is a `Guid`.
- [x] 3.2 Add `Services/Transfer/ExportJson.cs` with a static `JsonSerializerOptions`:
  - `JsonSerializerDefaults.Web`
  - a `JsonStringEnumConverter` with no naming policy
  - `WriteIndented = true`

  A comment says the file's shape is a contract with 04 and with future builds, and is deliberately independent of MVC's JSON options.
- [x] 3.3 Add `Services/Transfer/IExportService.cs` and `ExportService.cs`, with an `ExportAsync(string? userAgent, CancellationToken ct)` method:
  - Its constructor takes `AnimeTrackerDbContext`, `ITopAnimeSelectionRepository` and `IActivityLogRepository`.
  - It opens a `RepeatableRead` transaction before the first read and disposes it after the last, never committing (D2).
  - It reads the device id and the five sections (D3).
  - It filters choices on the time alone, with no list join (D8).
  - Series blocks are built only where their time is non-null.
  - It orders every section per D9.
  - It sets `formatVersion` to 1, `device` to the stored id with `DeviceName.Describe(userAgent)` as its name, and `exportedAt` to now.
  - It returns the serialized UTF-8 bytes together with the file name.
- [x] 3.4 Add the file-name builder (D6): `bettermal-{first 8 hex digits of the device id}-{yyyyMMdd-HHmmss}.json`, from `exportedAt` in UTC
- [x] 3.5 Register `IExportService` as scoped in `Program.cs`. Add `Controllers/TransferController.cs` with `[HttpGet("api/transfer/export")]`, which passes `Request.Headers.UserAgent` to the service and returns `File(bytes, "application/json", fileName)` (D1)
